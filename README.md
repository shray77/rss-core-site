# 🛰️ rss-core-site

Публичная витрина статуса конвейера [rss-core](https://github.com/shray77/rss-core) на GitHub Pages.

**Открыть: [shray77.github.io/rss-core-site](https://shray77.github.io/rss-core-site/)**

## Как это работает

- `index.html` — статический дашборд: карточки источников, счётчики, легенда статусов.
- `status.json` — **перезаписывается автоматически воркером rss-core** после каждого прогона (крон каждые 2 часа или кнопка run-now). Руками не редактировать.

## Зачем отдельная публичная репа

GitHub Pages работает на бесплатном тарифе только для публичных репозиториев. Код лежит в приватных репах, наружу выставлены только страницы и данные — воркеры коммитят JSON через GitHub API.

workers.dev заблокирован в РФ, поэтому вся пользовательская поверхность живёт здесь.

## Статусы источников

| индикатор | значение |
|---|---|
| 🟢 ok | источник опрашивается, данные свежие |
| 🟡 нет данных | источник жив, но давно не приносил новых записей |
| 🔴 ошибка | последний прогон упал (после 3 падений подряд — алерт) |
